- [Explicit-array review](reviews/EXPLICIT_ARRAY_COHERENCE_PROPOSAL.md), [future input review](FUTURE_INPUT_REVIEW.md) and [reuse handoff](REUSE_HANDOFF.md) remain proposals, not general input support or compatibility guarantees.

Issue format 0.10 scientific/approval rules, runtime admission restrictions, open decisions and JSON payload constraints remain unchanged. No pipeline, runtime or user interface was implemented or executed. Synthetic design exercises do not establish accuracy, real-user usability, time savings, formal FAIR compliance or arbitrary-file validation. Scientific approval, permissions, accessibility and suitability for a specified numerical use remain separate.
